# ПР №3 — метакласи, декоратори та патерни

Виконав: **Арсеній Антонець** · Група: **БІКСб22540**

Запуск (Python 3.10+):

```console
python practical_03.py
```

Один файл демонструє автозапис плагінів власним метакласом і через `type()`, `__init_subclass__`, дескриптор `__set_name__`, декоратори `cache`, `rate_limit`, `log`, класові декоратори `auto_repr`, `frozen`, `log_methods`, Singleton, Factory Method, Observer, Strategy та MVC для списку задач.

`report.pdf` містить титульну сторінку, мету, аналіз рішень, результати демонстрації, висновки й джерела. `demo.png` — знімок консолі з запуском.
